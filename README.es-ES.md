PvP Chronicle es un complemento de Dalamud para registrar y revisar partidas PvP de FINAL FANTASY XIV. Permite consultar el historial y las repeticiones de Frontline y Crystalline Conflict, los objetivos del mapa, las estadísticas de rendimiento y una revisión de integridad del comportamiento limitada expresamente a las pruebas observables.

## Instalación

1. Instala e inicia XIVLauncher con Dalamud activado.
2. Abre **Dalamud Settings → Experimental**.
3. Añade la siguiente URL de repositorio personalizado:

   ```text
   https://raw.githubusercontent.com/chefiffer/dalamud-plugins/main/repo.json
   ```

4. Abre el instalador de complementos, busca **PVP Chronicle** y selecciona **Install**.

## Funciones principales

- Historial local y repetición detallada de partidas de Frontline y Crystalline Conflict.
- Líneas de tiempo de puntuación, KDA, flujo de combate, derrotas, movimiento, marcadores y objetivos observables.
- Calendario PvP, rotación de mapas, mecánicas específicas de cada mapa e interfaz localizada.
- Carga opcional para obtener Logs generados por el servidor y distribuciones de referencia.

PvP Chronicle no automatiza el juego, no ejecuta acciones de combate, no revela estados ocultos del juego ni considera las observaciones incompletas como prueba definitiva de trampas.

## Contribuir

Crea un fork del repositorio y una rama centrada en un cambio concreto, añade pruebas para el comportamiento afectado y abre una pull request hacia `main`.

No envíes capturas de partidas, conjuntos de datos de jugadores, tokens de acceso, direcciones de servidores privados ni datos personales de otros usuarios. Informa de los problemas de seguridad conforme a [`SECURITY.md`](SECURITY.md).
