PvP Chronicle é um plugin do Dalamud para registrar e analisar partidas PvP de FINAL FANTASY XIV. Ele oferece histórico e replay de Frontline e Crystalline Conflict, objetivos de mapa, estatísticas de desempenho e uma revisão de integridade comportamental estritamente limitada às evidências observáveis.

## Instalação

1. Instale e inicie o XIVLauncher com o Dalamud ativado.
2. Abra **Dalamud Settings → Experimental**.
3. Adicione a URL abaixo como repositório personalizado:

   ```text
   https://raw.githubusercontent.com/chefiffer/dalamud-plugins/main/repo.json
   ```

4. Abra o instalador de plugins, procure **PVP Chronicle** e selecione **Install**.

## Destaques

- Histórico local e replay detalhado de partidas de Frontline e Crystalline Conflict.
- Linhas do tempo de pontuação, KDA, fluxo de combate, derrotas, movimento, marcadores e objetivos observáveis.
- Calendário PvP, rotação de mapas, mecânicas específicas de cada mapa e interface localizada.
- Envio opcional para obter Logs gerados pelo servidor e distribuições de referência.

PvP Chronicle não automatiza a jogabilidade, não executa ações de combate, não revela estados ocultos do jogo e não trata observações incompletas como prova definitiva de trapaça.

## Como contribuir

Faça um fork do repositório, crie uma branch para uma alteração específica, acrescente testes do comportamento afetado e abra um pull request para `main`.

Não envie capturas de partidas, conjuntos de dados de jogadores, tokens de acesso, endereços de servidores privados nem dados pessoais de outros usuários. Relate problemas de segurança conforme [`SECURITY.md`](SECURITY.md).
