PvP Chronicle ist ein Dalamud-Plugin zum Aufzeichnen und Auswerten von PvP-Partien in FINAL FANTASY XIV. Es unterstützt den lokalen Verlauf und die Wiedergabe von PvP-Front und Crystalline Conflict, Kartenziele, Leistungsstatistiken sowie eine Verhaltensprüfung, die ausdrücklich auf beobachtbare Belege begrenzt ist.

## Installation

1. Installiere und starte XIVLauncher mit aktiviertem Dalamud.
2. Öffne **Dalamud Settings → Experimental**.
3. Füge diese benutzerdefinierte Repository-URL hinzu:

   ```text
   https://raw.githubusercontent.com/chefiffer/dalamud-plugins/main/repo.json
   ```

4. Öffne den Plugin-Installer, suche nach **Battlefield Frontline Collector** und wähle **Install**.

## Wichtigste Funktionen

- Lokaler Partieverlauf und detaillierte Wiedergabe für PvP-Front und Crystalline Conflict.
- Zeitleisten für Punkte, KDA, Kampfverlauf, K. o., Bewegung, Markierungen und beobachtbare Ziele.
- PvP-Kalender, Kartenrotation, kartenspezifische Mechaniken und lokalisierte Benutzeroberfläche.
- Optionaler Upload für serverseitig erzeugte Logs und Referenzverteilungen.

PvP Chronicle automatisiert das Spiel nicht, führt keine Kampfkommandos aus, legt keine verborgenen Spielzustände offen und behandelt unvollständige Beobachtungen nicht als endgültigen Beweis für Betrug.

## Mitwirken

Forke das Repository, erstelle einen fokussierten Branch, ergänze Tests für das betroffene Verhalten und öffne einen Pull Request gegen `main`.

Übermittle keine Partiemitschnitte, Spielerdatensätze, Zugriffstoken, privaten Serveradressen oder personenbezogenen Daten anderer Benutzer. Melde Sicherheitsprobleme gemäß [`SECURITY.md`](SECURITY.md).
