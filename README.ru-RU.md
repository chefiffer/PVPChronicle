PvP Chronicle — плагин Dalamud для записи и разбора PvP-матчей FINAL FANTASY XIV. Он поддерживает историю и повторы Frontline и Crystalline Conflict, цели на карте, статистику эффективности и проверку целостности поведения, ограниченную только наблюдаемыми свидетельствами.

## Установка

1. Установите и запустите XIVLauncher с включённым Dalamud.
2. Откройте **Dalamud Settings → Experimental**.
3. Добавьте следующий адрес пользовательского репозитория:

   ```text
   https://raw.githubusercontent.com/chefiffer/pvpchronicle/main/repo.json
   ```

4. Откройте установщик плагинов, найдите **Battlefield Frontline Collector** и выберите **Install**.

## Основные возможности

- Локальная история матчей и подробные повторы Frontline и Crystalline Conflict.
- Временные шкалы счёта, KDA, хода боя, смертей, перемещений, меток и наблюдаемых целей.
- PvP-календарь, ротация карт, механики отдельных карт и локализованный интерфейс.
- Необязательная отправка данных для получения рассчитанных сервером Logs и эталонных распределений.

PvP Chronicle не автоматизирует игровой процесс, не выполняет боевые действия, не раскрывает скрытое состояние игры и не считает неполные наблюдения окончательным доказательством нечестной игры.

## Участие в разработке

Создайте форк репозитория и отдельную ветку для конкретного изменения, добавьте тесты затронутого поведения и откройте pull request в `main`.

Не отправляйте записи матчей, наборы данных игроков, токены доступа, адреса частных серверов и персональные данные других пользователей. Сообщайте о проблемах безопасности согласно [`SECURITY.md`](SECURITY.md).
